# BloodPSP Launcher

1. Extract the ZIP and open `BloodPSPLauncher.exe`. Keep `_internal` beside it.
2. Select your **Blood: Fresh Supply** or **One Unit Whole Blood** installation.
3. Select the PSP memory stick or an output folder and click **BUILD PSP FOLDER**.
4. Copy the generated `PSP` folder to your memory stick if you built it on the PC.

The included EBOOT is selected automatically. **Browse** selects another one;
**Download latest from GitHub** gets the latest published version.

In **Controls**, change the actions or use **Map button** to record a button or
combination with a DualShock/DualSense. You can also use **On-screen buttons**.
Use **Save preset** and **Load preset** to keep your layouts.

With the game closed, click **Apply controls**, then start the game.
**Edit output CFG** opens the configuration of the game folder you built.

OGG music and user maps are copied automatically when available.
The original game files are not included. Your files and existing saves are kept.
