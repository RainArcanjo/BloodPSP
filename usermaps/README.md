# User maps / Mapas personalizados

Place Blood `.MAP` files in `usermaps/` beside `EBOOT.PBP`, then choose
**NEW GAME > USER MAP**, select a map with **X**, and choose the difficulty.
The PSP build creates this folder automatically when it starts.

Coloque arquivos `.MAP` de Blood em `usermaps/`, ao lado da `EBOOT.PBP`.
No jogo, abra **NEW GAME > USER MAP**, escolha o mapa com **X** e selecione
a dificuldade. A build PSP cria esta pasta automaticamente ao iniciar.

Both uppercase `.MAP` and lowercase `.map` filenames are supported. Subfolders
can be browsed using the existing file picker. `.BAK` files are editor backups
and are not needed. If a map comes with a matching `.DEF` description, keep it
beside the map. Maps requiring replacement art or other custom resources may
need additional installation steps from their authors.

Arquivos `.BAK` sao backups do editor e nao sao necessarios. Caso exista um
arquivo `.DEF` de descricao, mantenha-o junto do mapa. Siga as instrucoes do
autor para mapas que exigem recursos adicionais. Mapas de teste e conteudo de
terceiros nao fazem parte deste repositorio.
